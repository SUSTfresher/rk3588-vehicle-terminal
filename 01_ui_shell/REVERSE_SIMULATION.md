# 模拟倒车闭环

## 协议

每行一条 JSON，当前版本为：

```json
{"version":1,"speed_kmh":0,"gear":"R"}
```

`gear` 支持 `P`、`D`、`R`。本版约束 P/R 挡车速必须为 0；客户端在解析层拒绝不符合约束的消息。

## 模拟器周期

`vehicle_simulator` 每100ms更新一次：P挡等待约3秒，D挡加速到60、保持、减速到0，R挡保持约4秒，然后回到P挡。
模拟器只负责提供上游车辆状态，不依赖 Qt 界面。

## 界面行为

主界面收到 R 后切换到摄像头页并隐藏全局导航；收到 P/D 后，如果这次切换是由 R 自动触发，则回到车辆状态页。
手动进入摄像头页不设置自动返回标志，便于独立测试摄像头。

## 板端验证

需要同时重新编译模拟器和界面：

```bash
cd ~/vehicle_terminal/01_ui_shell/build-simulator
qmake ../simulator.pro
make -j2

cd ..
qmake terminal.pro
make -j2
```

运行模拟器后，观察日志或界面：D挡行驶结束、R挡出现时应自动进入摄像头；约4秒后回到车辆状态。
如果只想测试手动摄像头，直接点击摄像头页即可，R挡自动逻辑不会抢占已经手动打开的页面。
