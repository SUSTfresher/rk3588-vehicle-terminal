# 地图地点搜索（第一版）

## 范围与操作

地图页点击“搜索”展开左侧面板。可点击“西安北站”“陕西科技大学”快捷词，
或用键盘填写关键词后点击“查找”/按回车。第一版限定西安市，最多显示前10个候选。
自定义中文输入需要板端可用的输入法；本次没有安装中文输入法或屏幕键盘。
快捷词不需要输入法，均通过在线接口取得结果，没有内置假搜索坐标。

点击结果后收起面板，在地图上显示红色地点标记，缩放到16级。
标记随地图拖动、缩放。“陕科大”恢复原校区示例位置并清除标记。
选中地点不是车辆当前位置，没有 GPS 定位、路线规划或导航播报。

## 代码分工

- `map_search_client.h/.cpp`：读取原来的 Key 文件、构造请求、12秒超时、取消旧请求、解析结果。
- `map_page.cpp`：输入与快捷词、可滚动候选列表、地图地理坐标标记；兼容Qt5/Qt6触点读取。
- `terminal.pro`：注册新增源文件和头文件，仍只需要现有 Widgets / Network 依赖。

依据[天地图官方搜索V2文档](https://lbs.tianditu.gov.cn/server/search2.html)，
请求 `https://api.tianditu.gov.cn/v2/search`，使用 `queryType=12`、
`specify=156610100`（西安市）、`start=0`、`count=10`。经纬度取自返回的 `pois[].lonlat`。
状态码1000表示正常，3001表示无结果。HTTP200本身不代表服务授权/业务成功。

地图瓦片和搜索都读取 `~/.config/vehicle-map-probe/tianditu.key`，无需复制Key到源码。
地图瓦片可用不保证搜索接口已获授权，真实权限和网络需要板端验收。
请求不跟随重定向、不忽略TLS错误，不打印URL、Key或原始响应。仅记录HTTP状态、
网络错误数字、超时与结果数量。返回体上限512KiB，丢弃无效坐标。
新搜索、修改输入、收起面板或离开地图都会取消正在执行的旧搜索。

## 上传与编译

需要同步 `map_page.cpp`、`map_search_client.h`、`map_search_client.cpp`、`terminal.pro`。
在板上先退出旧程序，再执行：

```bash
cd ~/vehicle_terminal/01_ui_shell
qmake terminal.pro && make -j2
QT_QPA_PLATFORM=linuxfb QT_QPA_FB_HIDECURSOR=1 ./vehicle_terminal
```

## 验收

1. 更多→在线地图→搜索→西安北站：出现真实候选列表，点击后定位、出现标记。
2. 拖动、缩放地图，标记仍对应原地点；陕科大按钮恢复校区示例。
3. 陕西科技大学快捷词、空输入、不同关键词各试一次，错误提示不阻塞返回。
4. 网络不可用时约12秒内显示失败；恢复网络后可重新查找。
5. 连续搜索或请求中收起/返回，没有旧结果突然覆盖当前面板。
6. 返回车辆状态、进出摄像头，底部导航仍完整，窗口720×480。

## 本地验证与限制

`../03_map_search_test` 是不依赖摄像头/GStreamer的离线测试，使用合成响应，
验证请求编码、状态码、无结果、非法坐标、候选选择、地理标记、清除结果和窗口布局。
在未配置地图Key的桌面账户中用qmake编译并以 `QT_QPA_PLATFORM=offscreen` 运行。
本地使用Qt6.11.2；真实天地图授权、Qt5.12板端编译和触摸仍需实机验证。
