# 横屏音乐页

## 结构

main.cpp 的导航不变。media_page.cpp 内的 MediaPage 管理歌曲列表、界面和循环策略，
RecordCover 绘制唱片，TransportButton 绘制图标，ElidedLabel 对长文字做省略。
AudioPlayer 管理 GStreamer，新增播放状态、进度、标签、播放结束信号和 seek 方法。
不创建顶层弹窗：播放列表直接在音乐页内切换。切换底部导航不会停止音乐。

## 音频与封面

在可执行文件旁的 media 目录放 MP3/WAV/FLAC/OGG，可使用中文文件名，
不用改成 test.mp3。是否可解码仍取决于板端插件。按名称排序，只扫描本层目录。
例如“第一首.mp3”配“第一首.jpg”，也支持同名 .png / .jpeg。
如果多首歌共用一张封面，也可在 media 中放 cover.jpg、cover.png 或 cover.jpeg。
没有图片显示默认山景唱片，本版不提取内嵌封面。
歌名/歌手优先读取音频标签，缺失时显示文件名/本地音频。
列表显示文件名；点击“刷新歌曲”可以识别新上传文件。

## 操作

- 播放/暂停共用中间按钮，继续时保留位置。
- 手动上一首/下一首首尾相接并立即播放；仅一首时从头重播。
- 顺序播放自然结束后播放下一首，末首结束停止。
- 列表循环末首结束后回第一首；单曲循环自然结束后重播当前曲目。
- 点击列表曲目从头播放并返回播放页。
- 每250ms更新进度，松开滑块时跳转，未知时长禁用滑块；页面会提示可拖动进度条。
- 刷新保留仍存在的当前歌曲；当前文件被移除则停止并选中第一首。
- 缺失/损坏歌曲报错，不会自动无限跳过坏文件。

音量保持20%，声卡仍为 plughw:CARD=rockchipes8388,DEV=0。
暂不支持网络、音量控件、保存播放位置。停止按钮被播放/暂停布局取代，后端保留stop用于切歌和结束。

## 验证

旧版MP3播放已由用户验证；ID3插件问题安装GStreamer插件后解决。
此新版完成源码检查，本机缺少Qt/GStreamer开发库，未编译，实机外观待确认。
板端运行 qmake terminal.pro，再 make -j2。

准备两首短歌及一张同名封面，验证：
1. 720×480布局、长文件名省略、同名封面与默认封面。
2. 播放/暂停/继续，时长进度，拖动进度跳转。
3. 上一首/下一首、列表选曲/返回，声音标题封面一致。
4. 拖近结尾检查顺序播放、列表循环、单曲循环。
5. 播放时切到车辆页，检查音乐、时钟、触摸、车辆数据。
6. 刷新列表、错误后重试，界面保持可用。

GStreamer总线每50ms非阻塞读取，每轮最多32条。
进入NULL释放资源仍同步执行，切歌耗时需实机观察，未声称硬实时。
